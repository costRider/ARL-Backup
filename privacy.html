개인정보처리방침 / Privacy Policy

ARL Backup은 단일 운영자가 자신의 NAS를 Google Drive에 암호화 백업·복원하기 위한 개인용 도구입니다. 공개 고객 서비스, 회원 가입, 광고 추적, 이용자 분석 기능을 제공하지 않습니다.

1. 접근하는 데이터 / Data accessed

운영자가 승인한 Google Drive OAuth 접근 권한을 사용하여 Drive 파일과 폴더를 조회하고 백업 파일을 업로드·다운로드합니다. 현재 권한 범위는 Google Drive 전체 접근(scope: drive)이며, 단일 백업 폴더로만 권한이 기술적으로 제한된 것은 아닙니다. 실제 백업 스크립트는 ARL 백업 경로만 대상으로 구성합니다.

2. 이용 목적 / Purpose

PostgreSQL 덤프, 작업 상태, 운영 설정(비밀정보 제외) 및 무결성 체크섬을 백업하고, 장애 발생 시 복원하기 위해 사용합니다. Drive 데이터를 광고, 타깃 마케팅, 프로파일링 또는 판매 목적으로 사용하지 않습니다.

3. 저장 및 보안 / Storage and security

백업 자료는 기기에서 rclone crypt를 통해 암호화한 후 Google Drive에 저장됩니다. OAuth 토큰은 운영자가 관리하는 NAS의 rclone 설정에 로컬로 보관됩니다. 암호화 암호 및 복구 키는 별도로 안전하게 보관해야 합니다. 데이터 및 백업의 보존과 삭제는 운영자가 직접 통제합니다.

4. 제3자 제공 / Sharing

도구 운영자는 백업 파일이나 Google 계정 데이터를 제3자에게 판매하거나 광고용으로 제공하지 않습니다. 백업 전송·저장에는 Google Drive, 이 공개 안내 페이지 제공에는 GitHub Pages가 사용됩니다. 해당 서비스의 자체 처리에는 각각의 서비스 정책이 적용됩니다.

5. 접근 권한 철회 및 삭제 / Revocation and deletion

운영자는 Google 계정의 제3자 앱 연결 설정에서 언제든 ARL Backup 접근 권한을 철회할 수 있습니다. 백업 파일은 운영자가 Google Drive에서 직접 삭제할 수 있습니다. 권한 철회는 이미 저장된 백업 파일을 자동 삭제하지 않습니다.

6. 문의 / Contact

본 개인용 프로젝트 관련 문의는 GitHub 저장소를 통해 할 수 있습니다. 공개 이슈에는 이메일, OAuth 토큰, 인증정보, 백업 내용을 남기지 마세요.

English summary

ARL Backup is a private, single-operator backup utility. Its current rclone connection requests full Google Drive access to list, upload, download and verify backup files, although the backup scripts target only an ARL-designated folder. Backup payloads are encrypted locally before upload. OAuth tokens are kept in local rclone configuration. The operator does not sell or use Drive data for advertising. Google Drive hosts encrypted backups; GitHub Pages hosts this public information page. The operator may revoke access through Google Account settings and delete stored backups manually.
