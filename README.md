# ARL Backup — Public OAuth information site

Public information pages for a **personal-use** NAS encrypted-backup utility.

- Home: `index.html`
- Privacy policy: `privacy.html`
- Styling: `style.css`

This repository **does not** contain the ARL Core backend, production credentials, Google OAuth client secret, rclone configuration, keys, or private backups.

## Activate GitHub Pages

In **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then **Save**. Verify the live URL and the privacy page in a private browsing window.

Expected URL patterns **after** activation (not yet verified as live):

- https://costRider.github.io/ARL-Backup/
- https://costRider.github.io/ARL-Backup/privacy.html

## Google OAuth branding

Provide the verified GitHub Pages URLs in Google Auth Platform where accepted. Google may require authorized-domain ownership verification or other checks; GitHub Pages does **not** guarantee Production approval. Do not publish real keys, tokens, NAS addresses or backups in this repository.
